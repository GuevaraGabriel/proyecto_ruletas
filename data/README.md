# Carpeta data

Esta carpeta contiene los datos de entrada utilizados
en el proyecto.

## Contenido previsto

- Números de las ruletas europea y americana.
- Clasificación de los números por color.
- Clasificación por docenas y columnas.
- Información sobre probabilidades y pagos.

Los datos originales se conservarán sin modificaciones.

Los resultados de las simulaciones se guardarán
en la carpeta res.
