# Carpeta config

Esta carpeta contiene los parámetros de configuración
utilizados en las simulaciones del proyecto.

## Contenido previsto

- Tipo de ruleta: europea o americana.
- Cantidad de giros por sesión.
- Número de sesiones simuladas.
- Monto fijo apostado por giro.
- Estrategia de apuesta seleccionada.
- Semilla aleatoria para reproducir los resultados.

Los parámetros permitirán ejecutar diferentes
escenarios manteniendo una metodología consistente.
