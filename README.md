# Simulación de estrategias de ruleta

## Descripción
Proyecto individual del curso Herramientas de Datos I.

Análisis comparativo de las ruletas europea y americana mediante simulaciones en R.

Se estudiarán cuatro estrategias:
1. Apuesta a un número.
2. Apuesta a una docena.
3. Apuesta a un color.
4. Apuesta combinada a color y columna.

## Estructura
- cod/: scripts de R y Quarto.
- data/: datos de entrada.
- info/: fuentes y documentación.
- config/: parámetros de simulación.
- res/: resultados, gráficos y reporte.

## Herramientas
R, RStudio, tidyverse, ggplot2, Quarto y Git.
